# Leslie Hodges Gallagher CV

Professional CV built with Quarto markdown, generating both interactive HTML and print-ready PDF versions.

**View CV:** [https://lchogal.github.io/cv/](https://lchogal.github.io/cv/)

## Requirements

- [Quarto](https://quarto.org/)
- Python 3.11+
- weasyprint (for PDF generation): `pip install weasyprint`
- System dependencies: libpango-1.0-0, libpangoft2-1.0-0
